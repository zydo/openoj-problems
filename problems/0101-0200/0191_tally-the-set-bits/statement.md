# Tally The Set Bits

## Description

A positive integer `n` has some of its binary digits set to one.
Return how many there are — the count is often called the pattern's
population count.

### Example 1

```text
Input: n = 77
Output: 4
Explanation: The binary form 1001101 carries four ones.
```

### Example 2

```text
Input: n = 536870912
Output: 1
Explanation: The binary form 100000000000000000000000000000 carries a
single one.
```

### Example 3

```text
Input: n = 2000000000
Output: 13
Explanation: The binary form 1110111001101011001010000000000 carries
thirteen ones.
```

### Constraints

- `1 <= n <= 2³¹ - 1`
