# Digit-String Sum

## Description

Two non-negative whole numbers arrive as strings `num1` and `num2`. Add them
and return their sum as a string.

Do not use a big-integer library, and do not convert the inputs into integers.

### Example 1

```text
Input: num1 = "999", num2 = "1"
Output: "1000"
```

### Example 2

```text
Input: num1 = "2", num2 = "89"
Output: "91"
```

### Constraints

- `1 <= num1.length, num2.length <= 10⁴`
- `num1` and `num2` consist of only digits.
- Neither `num1` nor `num2` has a leading zero, except for the value zero
  itself.
