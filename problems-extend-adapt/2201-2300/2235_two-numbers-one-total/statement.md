# Two Numbers, One Total

## Description

You are given two integers `num1` and `num2`. Report the value obtained by
adding them together.

### Example 1

```text
Input: num1 = 8, num2 = 21
Output: 29
Explanation: 8 + 21 = 29.
```

### Example 2

```text
Input: num1 = -7, num2 = -9
Output: -16
Explanation: Both values are negative; -7 + (-9) = -16.
```

### Example 3

```text
Input: num1 = 0, num2 = 13
Output: 13
Explanation: Adding zero leaves the other value unchanged.
```

### Constraints

- `-100 <= num1, num2 <= 100`
