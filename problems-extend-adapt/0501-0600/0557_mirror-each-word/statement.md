# Mirror Each Word

## Description

You are given a string `s` made of one or more words separated by single
spaces, with no leading or trailing whitespace. Reverse the letters inside
each word individually, leaving the spaces and the left-to-right order of
the words untouched.

### Example 1

```text
Input: s = "Open the pod bay doors"
Output: "nepO eht dop yab srood"
```

### Example 2

```text
Input: s = "Hi there"
Output: "iH ereht"
```

### Constraints

- `1 <= s.length <= 5 * 10⁴`
- `s` contains printable ASCII characters.
- `s` does not contain any leading or trailing spaces.
- There is at least one word in `s`.
- All the words in `s` are separated by a single space.
