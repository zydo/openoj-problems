# Square Formation Check

## Description

Four points in the plane form a square exactly when their four sides are
equal in positive length and meet at right angles. Given four points in
arbitrary order, report whether they form a square.

### Example 1

```text
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,1]
Output: true
```

### Example 2

```text
Input: p1 = [0,0], p2 = [1,1], p3 = [1,0], p4 = [0,12]
Output: false
```

### Example 3

```text
Input: p1 = [1,0], p2 = [-1,0], p3 = [0,1], p4 = [0,-1]
Output: true
```

### Constraints

- Each point has exactly two coordinates in `[-10⁴, 10⁴]`.
