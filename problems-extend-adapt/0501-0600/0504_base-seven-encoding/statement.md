# Base Seven Encoding

## Description

You're given a signed integer `num`. Write out its value in base 7 and
return that as a string.

### Example 1

```text
Input: num = 55
Output: "106"
```

### Example 2

```text
Input: num = -19
Output: "-25"
```

### Example 3

```text
Input: num = 0
Output: "0"
```

### Constraints

- `num` fits within `[-10⁷, 10⁷]`.
