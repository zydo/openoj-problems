# Letter Count Match

## Description

You are given two strings, `s` and `t`. Determine whether `t` is a
rearrangement of the letters of `s` — every letter that appears in `s`
must appear in `t` exactly the same number of times, and vice versa.
Return `true` if the two strings are letter-for-letter rearrangements of
one another, and `false` otherwise.

### Example 1

```text
Input: s = "listen", t = "silent"
Output: true
```

### Example 2

```text
Input: s = "apple", t = "pale"
Output: false
```

### Constraints

- `1 <= s.length, t.length <= 5 * 10⁴`
- `s` and `t` consist of lowercase English letters.

### Follow-up

What if the two strings could contain arbitrary Unicode characters
instead of just lowercase English letters? How would your approach need
to change to handle that?
