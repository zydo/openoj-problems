# Bitwise Integer Addition

## Description

Given two integers `a` and `b`, produce their sum without using either the
`+` or `-` operator.

Use bit-level operations to combine the values. The returned value must be
the ordinary signed integer sum within the stated bounds.

### Example 1

```text
Input: a = -7, b = 12
Output: 5
Explanation: Combining -7 and 12 yields 5.
```

### Example 2

```text
Input: a = -8, b = -9
Output: -17
Explanation: The two negative addends total -17.
```

### Constraints

- `-1000 <= a, b <= 1000`
