# Added Letter Locator

## Description

String `t` contains all letters from `s` in an arbitrary order, plus one extra
lowercase letter. Identify and return that additional letter.

### Example 1

```text
Input: s = "mno", t = "onmp"
Output: "p"
```

### Example 2

```text
Input: s = "", t = "k"
Output: "k"
```

### Example 3

```text
Input: s = "balloon", t = "noballoz"
Output: "z"
```

### Constraints

- `0 <= s.length <= 1000`
- `t.length == s.length + 1`
- `s` and `t` consist of lowercase English letters.
